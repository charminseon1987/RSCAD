# 수식 · 그림 · 표 해설

## 수식 해설 절차 (순서 고정)
1. **식 원문** — LaTeX로 다시 쓰고 원문 식 번호를 단다. 캡처가 흐리면 추정한 부분을 `(?)`로 표시하고 사용자에게 확인받는다.
2. **기호 표** — 식에 나온 모든 기호를 `| 기호 | 의미 | 단위 | 비고 |` 표로 정의한다. `references/symbols.md`를 먼저 보고, 논문 정의가 다르면 논문 정의를 따르되 차이를 비고에 쓴다. 누락 확인: `python scripts/symbols_check.py "<LaTeX>"` 로 기호 목록을 뽑아 표와 대조한다.
3. **한 줄 의미** — 식이 무엇을 말하는지 한 문장. 예: "관성 J가 클수록 전력 변화에 대한 주파수 변화가 느려진다."
4. **항별 해설** — 각 항의 역할(구동·복원·감쇠·결합)을 설명한다.
5. **가정·적용 범위** — 선형화 운전점, 무시한 동특성, per-unit 기준, 평균화 모델 여부 등. 논문에 명시된 것은 ▸, 추정은 ※.
6. **차원 검증** — `symbols_check.py --units` 로 양변 단위를 확인한다. 불일치면 per-unit 식인지 먼저 의심하고 결과를 적는다.
7. **수치 예시** — 대표값(논문 표 또는 symbols.md 대표값)을 넣어 크기 감을 준다. 값의 출처를 밝힌다.
8. **내 연구 연결 (※)** — 22차 상태공간 모델(DC 8 + AC 14), PSO 파라미터, SCR–X/R 스윕 중 어디에 해당하는지. 모르면 "연결 불명"이라고 쓴다.

## 그림 해설
축(이름·단위·스케일) → 무엇을 비교하나(범례) → 핵심 경향 1~3개 → 읽을 수 있는 수치(경계값·교차점) → 이 그림이 뒷받침하는 저자 주장 → 한계(조건 범위, 생략된 경우).
- 근궤적/고유값 궤적: 파라미터 증가 방향, 허수축 교차점, 지배 모드를 반드시 짚는다.
- 시간 응답: 오버슈트, 정정시간, 진동 주파수 추정치.

## 표 해설
열 정의 → 비교 기준(기준 케이스) → 가장 큰 차이 2~3개 → 표만으로 말할 수 없는 것.

## 규칙
- 그림·표에서 읽은 수치는 "그림 판독값 약 ~"으로 쓰고, 정확한 값처럼 말하지 않는다.
- 유도를 요청받으면 한 단계씩, 각 단계에 사용한 연산(선형화, dq 변환, 라플라스 등)을 적는다.
- 확신 없는 해석을 사실처럼 쓰지 않는다 — ▸ / ※ 구분 유지.

## 출력 형식
- 채팅: 위 순서의 소제목 + 기호 표.
- Obsidian: `01_개념/` 노트용으로 frontmatter(`tags: [수식, 출처키]`) 추가.
- 스콜라 웹앱: `{"target":"eq(12)","latex":"...","symbols":[...],"meaning":"...","assumptions":[...],"units_ok":true,"link_to_my_research":"..."}`

## 하지 않는 것
- 전문 번역 (→ `paper-translate`), 논문 전체 요약 (→ `paper-note`)
