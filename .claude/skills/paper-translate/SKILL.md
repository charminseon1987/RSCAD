# 논문 1:1 번역

## 원칙
1. **문단 대응** — 원문 문단 1개 = 번역 문단 1개. 합치거나 쪼개지 않는다. 문단 번호 `[P3.2-4]`(3.2절 4번째 문단)를 양쪽에 붙인다.
2. **보존 대상 (절대 번역·수정 금지)** — 수식(`$...$`, 식 번호 `(12)`), 변수·기호(ω, J, D_p, SCR), 인용 번호 `[12]`, 그림·표 번호 `Fig. 5`, `Table II`, 단위, 수치.
3. **용어 통일** — `references/glossary.md`를 먼저 읽는다. 첫 등장 시 "국문(영문, 약어)" 1회 병기, 이후 국문 또는 약어. 용어집에 없는 용어는 번역 뒤 `(원어)`를 남기고 목록 끝에 "용어집 추가 후보"로 모은다.
4. **의역 금지** — 저자 주장의 강도를 바꾸지 않는다. may/could → "~할 수 있다", demonstrate → "입증한다", suggest → "시사한다".
5. **번역자 주석은 분리** — 설명이 필요하면 번역문 안에 넣지 않고 `※ 역주:`로 문단 아래에 따로 단다 (▸ = 원문 사실, ※ = 해석 규칙과 동일).

## 절차
1. PDF면 `python scripts/pdf_paragraphs.py <파일.pdf> -o paras.md` 로 문단을 번호 붙여 추출한다. 수식으로 보이는 줄은 `[EQ?]`로 표시되니 원문 PDF와 대조해 LaTeX로 옮긴다.
2. 요청 범위를 확인한다 — 전체 / 특정 절 / 초록만. 기본값은 **초록 + 서론 + 결론** 먼저, 나머지는 요청 시.
3. 절 단위로 번역한다. 한 번에 한 절, 끝날 때마다 다음 절 진행 여부를 묻지 않고 이어간다(사용자가 멈추라고 하면 멈춤).
4. 마지막에 `용어집 추가 후보` 목록을 출력한다.

## 출력 형식
기본은 교차 블록 (모바일·Obsidian 모두 가독성 좋음):

```
### [P2-1]
> The grid-forming (GFM) inverter regulates voltage magnitude and frequency ...
그리드포밍(grid-forming, GFM) 인버터는 전압 크기와 주파수를 ...
※ 역주: (필요할 때만)
```

- 사용자가 "표로"라고 하면 `| # | 원문 | 번역 |` 표로 출력.
- 웹앱(스콜라) 연동 시에는 `{"id":"P2-1","src":"...","ko":"...","note":null}` JSON 배열로 출력.

## 하지 않는 것
- 요약·평가 (→ `paper-note`), 수식 해설 (→ `equation-explain`), 인용 형식 변환 (→ `ieee-citation`)
- 원문에 없는 내용 보충
