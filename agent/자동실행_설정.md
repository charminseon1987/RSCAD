# schedule_agent 자동 실행 설정

## 1. 파일 배치

`daily_check.bat` 을 `C:\Users\hyese\Dev\RSCAD\agent\` 에 넣는다.

## 2. 수동 실행으로 먼저 확인

```
cd C:\Users\hyese\Dev\RSCAD\agent
daily_check.bat
```

지금은 경보 5건이 있으므로 바탕화면에 `_연구일정_경보.txt` 가 생겨야 한다.
`agent\logs\2026-08-31.txt` 도 함께 생긴다.

파일이 안 생기면 로그를 먼저 확인한다. 배치가 아니라 파이썬 쪽 문제일 가능성이 높다.

## 3. 작업 스케줄러 등록

관리자 권한 없이 실행된다. cmd 에 그대로 붙여넣는다.

```
schtasks /create /tn "ResearchSchedule" /tr "C:\Users\hyese\Dev\RSCAD\agent\daily_check.bat" /sc daily /st 09:00 /f
```

등록 확인:

```
schtasks /query /tn "ResearchSchedule"
```

즉시 한 번 실행해서 동작 확인:

```
schtasks /run /tn "ResearchSchedule"
```

해제:

```
schtasks /delete /tn "ResearchSchedule" /f
```

## 4. 동작 방식

| 상황 | 결과 |
|---|---|
| 경보 있음 | 바탕화면에 `_연구일정_경보.txt` 생성 + 풍선 알림 |
| 경보 없음 | 바탕화면 파일 **삭제**. 아무 알림 없음 |
| 로드 실패 | 경보와 동일 취급 (파일 생성). YAML 이 깨졌다는 뜻이므로 조용히 넘기면 안 된다 |

로그는 `agent\logs\` 에 날짜별로 쌓인다.

## 5. 설계 의도

**요약 보고를 하지 않는다.** 매일 "오늘도 순조롭습니다" 같은 알림이 오면
며칠 만에 무시하게 되고, 정작 중요한 날의 알림도 같이 묻힌다.
바탕화면에 파일이 있으면 볼 게 있는 것이고, 없으면 없는 것이다.

**파일을 지우는 동작이 중요하다.** 경보가 해소되면 스스로 사라져야
파일 존재 자체가 신호가 된다. 남아 있는 파일은 미처리 항목이다.

## 6. 주의

- PC 가 꺼져 있으면 그날은 건너뛴다. 놓친 경보는 다음 실행에서 다시 잡힌다
  (상태를 저장하지 않고 매번 재평가하므로).
- `month_1_start` 가 바뀌면 경보 시점이 전부 이동한다. 2026-05 로 확정한 값이
  맞는지 한 번 더 확인할 것.
