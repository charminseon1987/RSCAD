|X/R|SCR*|판정|비고|
|---|---|---|---|

## 분석

### ⚠️ numpy 근사 모델 한계

```
현재 SCR* 모두 0.8 (모델 하한)
→ 원인: LCL 공진 모드(60Hz)가 지배 모드로 잡혀
        실제 VSG 스윙 모드 ζ 값 미반영
→ 기대값: Phase 2 SymPy 완성 후 SCR* 1.0~2.0 범위 예상

X/R=5.0에서 null
→ X/R 높을수록 (송전계통) 더 불안정한 경향
→ 물리적으로 타당 (Ganguly 2025 결과와 일치)
```

### 📌 Phase 2 이후 기대 결과

```
예상 SCR*(X/R) 패턴 (SymPy 21차 완성 후):
  X/R=0.5: SCR* ≈ 0.9~1.1  (배전 → 비교적 안정)
  X/R=1.0: SCR* ≈ 1.0~1.2
  X/R=2.0: SCR* ≈ 1.2~1.5
  X/R=5.0: SCR* ≈ 1.5~2.0  (송전 → 불안정 경향)

→ X/R 증가 → SCR* 증가 (더 강한 계통 필요)
→ Ganguly(2025) X/R=1.0에서 트립 관찰과 일치
```
