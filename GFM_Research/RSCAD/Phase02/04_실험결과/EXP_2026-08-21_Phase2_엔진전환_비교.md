## 🔍 분석

### ▸ 관찰된 사실 (실험 결과)

```
1. sympy+numpy 엔진 전환 성공
   → /api/health: "engine": "sympy+numpy" 확인
   → A_CACHE: SCR={3.0, 2.0, 1.5, 1.0} 4개 로드

2. A_k(9,6) 이론값 완전 일치
   이론: idc0/(J·ω₀) = 0.6/(0.62×376.99) = 0.002567
   계산: 0.002567  →  오차 0.0001% ✅

3. stable=True 유지 (4개 SCR + 88포인트 전부)

4. ζ_min 변화: 0.2564 → 0.1642
   → numpy 근사가 LCL 공진 모드를 과대평가했던 것 보정

5. 88포인트 전 구간 ζ < 0.64
   → SCR* 경계 도출 불가 (boundaries 전부 null)

6. X/R=5.0에서 ζ 증가 경향
   → Ganguly(2025) 결과와 반대 → 모델 한계
```

### ※ 해석 (내 판단)

```
ζ_min 감소(0.25→0.16)는 나쁜 게 아님
→ numpy가 과대평가, sympy+numpy가 더 정확한 값
→ 실제 시스템도 0.64 미달이므로 PSO 최적화 필요성 확인

X/R=5.0 이상 경향은 AC 13×13 수동 모델 한계
→ 계통 임피던스 교차항이 단순화됨
→ Phase 2 추가 정밀화 또는 PSCAD 교차검증 필요

SCR* null은 현재 파라미터(기본값 수준)에서 예상된 결과
→ PSO 후 ζ ≥ 0.64 달성 시 SCR* 유효값 도출 예상
```

### ⚠️ 이슈

```
이슈 1: ζ < 0.64 (전 구간)
  → 원인: LCL 공진 모드(~180Hz)가 지배 모드
  → 해결: PSO로 Kpc, Kic, L1 최적화 (Phase 3)

이슈 2: X/R=5.0 경향 반전
  → 원인: AC 13×13 계통 임피던스 단순화
  → 해결: 계통 교차항 정밀화 또는 PSCAD 검증

이슈 3: SCR* null
  → 원인: 현재 파라미터에서 ζ 기준 미달
  → 해결: Phase 3 PSO 후 재실행
```
