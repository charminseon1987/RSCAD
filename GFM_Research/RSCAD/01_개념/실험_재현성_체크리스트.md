# 실험 재현성 체크리스트

> [!abstract] 기준
> **6개월 뒤의 내가, 또는 심사위원이, 이 폴더만 보고 같은 숫자를 다시 만들 수 있는가.**
> 하나라도 아니오면 그 결과는 논문에 쓸 수 없다.

## 1. 조건 (무엇을 계산했는가)

- [ ] 결과에 영향을 주는 모든 입력이 식별자에 반영됐는가 → [[실행_식별자_설계원칙]]
- [ ] 스윕 축은 파일명, 공통 조건은 폴더명으로 분리됐는가
- [ ] `meta.json`이 선언형이 아니라 누적 레지스트리인가
- [ ] 같은 명령을 다시 쳤을 때 결과가 같은가 (멱등성)
- [ ] 실패 지점부터 이어서 돌릴 수 있는가 (resume)

## 2. 검증 (그 숫자가 맞는가)

계산이 끝났다는 것과 맞다는 것은 다르다. **자기 자신과 비교하는 검증은 검증이 아니다.**

- [ ] 독립적인 방법으로 대조했는가 (심볼릭 ↔ 유한차분)
- [ ] 검증이 통과·실패를 실제로 가르는가 (항상 ✅면 항등식)
- [ ] 알려진 실패 모드를 상시 감시하는가 (커플링 효과 = 0 → [[블록삼각_함정]])
- [ ] 물리적으로 예상되는 경향이 나오는가 (SCR↓ → δ↑, 안정 여유↓)
- [ ] 모델의 유효 범위를 수치로 명시했는가 → [[소신호_선형화]]
- [ ] 다른 환경에서 같은 값이 나오는가 (Windows/Linux 재현 확인)

> [!danger] v0에서 실제로 벌어진 일
> `A_k(9,6)` 검증이 `idc0/(J·w0)`로 대입한 값을 `idc0/(J·w0)`와 비교하고 있었다.
> 항상 통과하는 항등식이었고, 그 사이 21차 모델은 블록삼각이라 13차와 같은 결과를 내고 있었다.

## 3. 데이터 (무엇이 남았는가)

- [ ] 원자료(`.npy`)와 요약(`.json`, `.md`)이 함께 저장되는가
- [ ] 동작점 `x0`도 저장되는가 (재계산·초기값 주입·시간영역 검증에 필요)
- [ ] 폴더 내용과 메타데이터가 일치하는가 (파일 8개인데 메타는 5개?)
- [ ] 폐기한 결과에 `model_version` 태그가 붙어 있는가 (`v0-invalid`)
- [ ] `latest/`가 어느 실행에서 왔는지 기록되는가 (`latest_copied_from`)

## 4. 코드 (어떻게 계산했는가)

- [ ] 결과 폴더에서 코드 버전을 역추적할 수 있는가 (`model_version`)
- [ ] 폐기한 코드를 지우지 않고 `_archive/`에 보존했는가
- [ ] 파일명이 하는 일과 일치하는가 (`sym.py`인데 sympy가 없으면 ❌)
- [ ] 같은 목적의 파일이 여러 버전으로 굴러다니지 않는가 (`sym v0/v1/v2`)
- [ ] 하드코딩된 상수가 없는가 (전부 인수 또는 명시적 상수 블록)

## 5. 환경

- [ ] Python 버전과 핵심 패키지 버전이 기록됐는가 (numpy, scipy, sympy)
- [ ] `requirements.txt` 또는 `pip freeze` 결과가 저장소에 있는가
- [ ] OS 의존 코드가 없는가 (경로 구분자, 인코딩)
- [ ] 난수를 쓴다면 시드가 고정·기록되는가 ← **PSO에서 필수**

## 6. 문서

- [ ] 결과 폴더마다 Obsidian용 `.md` 요약이 자동 생성되는가
- [ ] 실패와 그 원인이 기록됐는가 (성공만 남기면 같은 실수를 반복한다)
- [ ] 판단 근거가 남았는가 ("왜 22차인가", "왜 SOC를 뺐는가")
- [ ] 미해결 항목이 체크박스로 추적되는가

## 단계별 추가 항목

### PSO (Phase 4~5)

- [ ] 난수 시드 고정 및 기록
- [ ] 목적함수 정의가 결과와 함께 저장되는가
- [ ] 수렴 이력(세대별 최적값)이 남는가
- [ ] 여러 시드로 반복해 재현성을 확인했는가

### CHIL (Phase 6~7)

- [ ] RSCAD 케이스 파일 해시
- [ ] DSP 펌웨어 빌드 ID
- [ ] GTIO 스케일링 상수와 채널 매핑
- [ ] 타임스텝 / substep 설정
- [ ] pre-processor 재컴파일 여부와 소요 시간
- [ ] 측정 원파형(raw) 보존 — 후처리 결과만 남기면 재분석 불가
- [ ] 실험 일시와 장비 상태 (온도, 사전 웜업)

## 논문 제출 직전

- [ ] 논문의 모든 표·그림이 어느 실행 폴더에서 나왔는지 추적 가능한가
- [ ] TABLE I / II의 숫자를 스크립트 실행으로 재생성할 수 있는가
- [ ] 심사 질의에 "그 조건으로 다시 돌려보겠습니다"가 가능한 상태인가
