# 💡 참여인자 & 지배 모드

## 한 줄 정의

> 21개 고유값(모드) 중 어떤 상태변수가 어떤 모드를 지배하는지 정량화하는 지표 — PSO 목적함수 설계의 핵심 입력

---

## 수식

$$P_{ki} = \phi_{ki} \cdot \psi_{ki}$$

|기호|의미|
|---|---|
|$\phi_{ki}$|우 고유벡터 k번째 원소 — 모드가 상태변수에 미치는 영향|
|$\psi_{ki}$|좌 고유벡터 k번째 원소 — 상태변수가 모드에 기여하는 정도|
|$P_{ki}$|i번 모드에 대한 k번 상태변수의 참여도|

$$\sum_k P_{ki} = 1 \quad \text{(정규화)}$$

---

## 계산 방법 (Python)

```python
import numpy as np
from scipy import linalg

# A_num: 21×21 야코비안
eigs, right_vecs = linalg.eig(A_num)          # 우 고유벡터
_, left_vecs     = linalg.eig(A_num.T)         # 좌 고유벡터 (전치)

# i번 모드의 참여인자
i = 0  # 첫 번째 모드
phi = right_vecs[:, i]   # 우 고유벡터
psi = left_vecs[:, i]    # 좌 고유벡터

P = np.abs(phi * psi)    # 원소별 곱
P = P / P.sum()          # 정규화

# 지배 상태변수 (P_ki > 0.15)
dominant = [(k, P[k]) for k in range(21) if P[k] > 0.15]
```

## 직관적 이해

```
고유값 λ₁ = -0.5 ± 3j 가 있을 때:

참여인자 계산 결과 (예시):
  P(Δω=x9,  λ₁) = 0.82  ← 가장 큼 → 지배 상태변수
  P(Pfilt=x10, λ₁) = 0.11
  P(udc=x6,  λ₁) = 0.03

→ λ₁은 "VSG 스윙 모드" (Δω가 지배)
```

## PSO 목적함수에서의 역할

```
PSO 최적화 대상:
  전체 21개 모드 ζ를 다 볼 필요 없음
  → P_ki > 0.15 인 지배 모드만 선정
  → 이 모드들의 ζ ≥ 0.64 달성에 집중

F_multi 구성:
  F2 = Σ (ζ_dominant - 0.707)²   ← 지배 모드만
  F3 = Σ max(0, 0.64 - ζ_dominant)

장점:
  - LCL 공진(180Hz)처럼 제어 불가한 모드 제외
  - VSG 스윙·DC-AC 커플링 모드에 집중
  - PSO 수렴 속도 향상
```
