# 💡 88포인트 2D 스윕 설계

## 한 줄 정의

> SCR 22레벨 × X/R 4조건 = 88개 운전점에서 야코비안 계산 → SCR*(X/R) 2D 안정 경계 도출

## 설계 기준

```python
SCR_list = [round(5.0 - i*0.2, 1) for i in range(22)]
# = [5.0, 4.8, 4.6, ..., 1.0, 0.8]  22레벨

XR_list = [0.5, 1.0, 2.0, 5.0]  # 배전~송전 대표값

총 포인트 = 22 × 4 = 88개
```

## SCR* 정의

$$ \text{SCR}^*(X/R) = \min { \text{SCR} \mid \zeta_{\min}(\text{SCR}, X/R) \geq \zeta_{\text{threshold}} } $$

> 각 X/R 조건에서 ζ ≥ 0.64를 처음 만족하는 최솟값 SCR
