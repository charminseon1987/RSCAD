# 💡 동작점 & 평형점 (x₀ 계산)

## 한 줄 정의

> 소신호 선형화의 기준점 — f(x₀) = 0을 만족하는 정상상태 운전점으로, SCR_k마다 갱신됨

---

## 평형점 조건

$$f(x_0) = 0 \quad \Rightarrow \quad \dot{x} = 0 \text{ (정상상태)}$$

```
정상상태에서:
  dΔω/dt = 0  → P_ref = P_filt (전력 균형)
  du_dc/dt = 0 → i_Lpv*(1-dpv) = i_dc_inv (DC 전력 균형)
  di_id/dt = 0 → 전압·전류 루프 수렴
```

---

## SCR별 동작점 계산 순서

### Step 1. 계통 임피던스 계산

$$Z_g = \frac{V_n^2}{SCR \cdot P_{rated}}, \quad R_g = \frac{Z_g}{\sqrt{1+(X/R)^2}}, \quad L_g = \frac{R_g \cdot (X/R)}{\omega_0}$$

### Step 2. PCC 전압 계산 (1차 Thevenin 근사)

$$V_{pcc,k} = V_n - (I_{d0} \cdot R_{g,k} + I_{q0} \cdot X_{g,k})$$

### Step 3. PV 동작점 (MPPT)

$$V_{pv0,k} \approx 0.8 \cdot V_{oc}(T), \quad I_{pv0,k} = \frac{P_{mppt}}{V_{pv0,k}}$$

### Step 4. DC 버스 전류 ← DC-AC 커플링 핵심

$$i_{dc0,k} = \frac{P_{pv,k}}{V_{dc0}} = \frac{0.9}{SCR_k}$$

> SCR이 낮아질수록 i_dc0 증가 → A_k(9,6) 증가

## 21개 상태변수 동작점 벡터

```python
x0 = np.array([
    0.0, 0.0, 0.0,      # xPI1,2,3 = 0 (정상상태 오차 없음)
    Vpv0, 0.9, 1.0,     # upv, ubat, udc=Vdc0
    0.9, 0.1,           # iLpv=idc0*Vdc0/Vpv0, iLbat
    0.0,                # Δω = 0 (정상상태)
    1.0, 0.0,           # Pfilt=Pref, Qfilt=0
    0.0, 0.0,           # φ_vd, φ_vq = 0
    0.0, 0.0,           # γ_id, γ_iq = 0
    Id0, Iq0,           # iid=Id0, iiq=Iq0
    Vpcc, 0.0,          # uod=Vpcc, uoq=0 (d축 정렬)
    Id0, Iq0,           # iod=Id0, ioq=Iq0
])
```

## SCR별 동작점 값

|SCR|Zg (pu)|Vpcc (pu)|idc0 (pu)|Δu_pv (%)|
|---|---|---|---|---|
|3.0|0.333|0.764|0.300|0.0|
|2.0|0.500|0.646|0.450|8.3|

> ▸ Δu_pv > 5% → 선형화 유효성 초과 → PSCAD Layer 2 교차검증 필요

---

## 선형화 유효성 기준

$$\Delta u_{pv} = \frac{|V_{pv0,k} - V_{pv0,nom}|}{V_{pv0,nom}} < 5%$$

```
SCR=3.0: Δu_pv=0.0%  → ✅ 유효
SCR=2.0: Δu_pv=8.3%  → ❌ 초과 (PSCAD 검증 필요)
SCR=1.5: Δu_pv=12.5% → ❌ 초과
SCR=1.0: Δu_pv=16.6% → ❌ 초과
```

## ⚠️ Phase 2 동작점 불일치 버그 (해결됨)

```
발생: sym.py 9차 시도 이전
원인: upv0=1.0, udc0=1.0, dpv0=0.5 설정 시
      f7=0 조건: upv = (1-dpv)*udc = 0.5 ≠ 1.0

```
