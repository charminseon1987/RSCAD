# 💡 이중수렴기준 설계

## 한 줄 정의

> PSO 종료 조건을 두 단계로 설계 — Phase 4a(임계값 결정)와 Phase 4b(N_final 결정)

## 2단계 MC 분석 구조

```
Phase 4a: threshold 결정 예비실험
  → 조건1·2 임계값 (0.1%, 0.5%) 검증
  → Shapiro-Wilk p > 0.10 확인

Phase 4b: N_final 결정 본실험
  → MC 30회 실행
  → IQR 분석으로 N_final 결정
  → 현재 추정: N_final ≈ 390
```

## N_final 결정 기준

```python
from scipy import stats

# MC 30회 실행 후
results = [pso_run() for _ in range(30)]
F_finals = [r['F_multi'] for r in results]

# 정규성 검정
stat, p = stats.shapiro(F_finals)
if p > 0.10:
    print("정규분포 → 평균 ± 표준편차 사용")
else:
    print("비정규 → IQR 사용")

# N_final: 수렴 반복 횟수 중앙값
N_finals = [r['n_iter'] for r in results]
N_final = int(np.median(N_finals))
```
