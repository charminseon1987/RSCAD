# 💡 소신호 선형화

## 한 줄 정의

> 비선형 동역학 f(x)를 동작점 x₀ 주변에서 1차 테일러 전개하여 선형 상태방정식 Δẋ = A·Δx로 근사하는 방법

## 수식

$$
\dot{x} = f(x) \approx f(x_0) + \left.\frac{\partial f}{\partial x}\right|_{x=x_0} \cdot (x - x_0) = A \cdot \Delta x
$$

$$
A = J(x_0) = \left.\frac{\partial f}{\partial x}\right|_{x=x_0} \quad \text{(야코비안 행렬)}
$$

## 유효 조건

```
Δu_pv = |Vpv0_k - Vpv0_nom| / Vpv0_nom < 5%
→ 초과 시 Layer 2 (PSCAD EMT) 교차검증 필요
```

## GFM 연구에서의 역할

```
비선형 f(x) (21개 방정식)
    ↓ 동작점 x₀(SCR_k) 대입
선형 야코비안 A_k (21×21)
    ↓ 고유값 분석
안정도 판정 + ζ_min + f_dom
    ↓
PSO 목적함수 입력
```
