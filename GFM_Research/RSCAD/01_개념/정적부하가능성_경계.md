# 정적 부하가능성 경계

> **저장 위치:** `01_개념/`

## 한 줄

2D SCR–X/R 경계도에는 성격이 다른 두 개의 선이 있다. **감쇠 경계**와 **정적 부하가능성 경계**. 하나로 합쳐 그리면 오독된다.

## 두 경계

| 구분 | 판정 | 물리 |
|---|---|---|
| 감쇠 경계 | σ_sync 또는 ζ_osc 가 기준 미달 | 소신호 불안정 |
| 부하가능성 경계 | 정상상태 해 부재 (δ → 90°) | `P = VE·sinδ / X` 전달 한계 |

▸ δ 추이 (X/R = 1.0): 22.42° → 32.58° → 42.42° → 62.34° → **78.95°**
▸ X/R = 1.0 에서 SCR 0.6 미수렴. X/R = 3.0 에서 SCR 0.8 이 δ=100.16°.
▸ 현재 스윕 범위에서 감쇠 경계는 **한 번도 발동하지 않았다.** 전 조건 안정.

> [!danger] 지금 상태로 88포인트를 돌리면
> 경계선이 전부 "동작점 미존재"로 그어진다. ζ·σ 기반 경계는 나타나지 않는다.
> 논문의 "강건성 경계" 정의를 이중 판정으로 바꿔야 한다.

## 미해결 결함 — δ > 90° 수용

▸ X/R = 3.0, SCR 0.8 에서 δ = 100.16° 인데 `stable = True` 로 보고된다.

cos(100.16°) = −0.176 이므로 동기화 계수 K = VE·cosδ/X 가 **음수**다. 동기화 토크가 음이면 δ 섭동이 발산해야 한다. 실수 양의 고유값이 나와야 정상이다.

※ `op.py` 의 `fsolve` 가 P–δ 곡선의 **하단 불안정 가지**를 잡고 있다. 대수적으로 유효한 근이지만 물리적 평형점이 아니다. 가지 선택이 초기값에 따라 달라져, X/R=1.0 에서는 SCR 0.6 이 미수렴하고 X/R=3.0 에서는 SCR 0.8 이 100° 로 "수렴"한다.

가드 (`runner.py`, `P2-A10`):

```python
DELTA_HARD = 90.0   # P-δ 곡선 불안정 가지 — 물리적 해 아님

if delta_deg >= DELTA_HARD:
    results[SCR] = {'converged': False,
                    'fail_reason': 'loadability_limit',
                    'message': f'δ={delta_deg:.2f}° > 90° (불안정 가지)'}
    x_prev, prev_delta = None, None   # 연속화 초기값 오염 방지
    continue
```

## 논문 관점

※ 두 경계를 다른 선종으로 겹쳐 그리는 것 자체가 기여가 될 수 있다. Dong et al.(2026) 은 1D SCR 스윕이므로 이 구분이 없다. 2D 로 확장하면서 경계의 성격이 영역에 따라 달라진다는 것을 보이면 **경계 정의 자체가 novelty** 가 된다.
