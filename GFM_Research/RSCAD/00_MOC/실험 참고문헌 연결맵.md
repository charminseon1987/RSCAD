## 실험 결과 자동 연결 체크리스트

결과가 나올 때마다:

```
□ stable 판정
  → True:  [1][7] 모델 검증 완료 표시
  → False: [7] Zhao 커플링 미반영 가능성 기록

□ A_k(9,6) 값
  → 이론값 일치: [7] Zhao 이론 검증 ✅ 기록
  → 불일치:      [7] 수식 재확인 필요 기록

□ f_dom 범위
  → 0.1~10Hz: VSG 스윙 모드 → [1] Table I과 비교
  → 60Hz:     LCL 공진 모드 우세 → numpy 근사 한계

□ SCR* 값
  → 0.8 (numpy 하한): Phase 2 이후 재측정 예정
  → 1.0~2.0: [3] Ganguly 트립 조건과 비교

□ ζ_min
  → ≥ 0.64: UNIFI V3 Category 3 만족
  → < 0.64: PSO 최적화 필요 → Phase 4
```
