# 📐 상태변수 선정근거

## 한 줄 정의

> 왜 22개인가 — 각 상태를 **포함한** 근거와 후보 중 **제외한** 근거의 기록

※ 심사에서 "왜 22차냐"를 물었을 때 답이 되는 문서. 차수는 목표값이 아니라 **유도 결과**여야 한다.

---

## 포함 판정 기준

상태변수는 아래 셋 중 하나에 해당할 때만 포함했다.

| # | 기준 | 물리적 의미 |
|---|---|---|
| C1 | 독립적인 에너지 저장 요소 | 인덕터 전류, 커패시터 전압 — 초기값을 독립적으로 줄 수 있음 |
| C2 | 제어기 적분 상태 | PI 적분기 출력. 과거 이력을 누적하므로 메모리를 가짐 |
| C3 | 위상·주파수 상태 | $\delta$, $\Delta\omega$ — 동기화 루프를 닫는 데 필수 |

제외 기준은 하나다.

| # | 기준 | 처리 |
|---|---|---|
| E1 | 시정수가 관심 대역(0.1–100 Hz) 밖 | 준정적(느림) 또는 대수식(빠름)으로 치환 |

## DC측 8개

| 기호 | 기준 | 근거 |
|---|---|---|
| `v_pv` | C1 | PV 단자 커패시터. 부스트 입력 동특성을 지배 |
| `i_Lpv` | C1 | 부스트 인덕터 전류 |
| `x_vpv` | C2 | PV 전압 제어 PI — MPPT 기준 추종 |
| `x_ipv` | C2 | 부스트 전류 루프 PI |
| `v_dc` | C1 | DC 링크 커패시터. **AC→DC 커플링의 수신점** |
| `i_Less` | C1 | ESS 컨버터 인덕터 전류 |
| `x_vdc` | C2 | DC 링크 전압 제어 PI |
| `x_iess` | C2 | ESS 전류 루프 PI |

▸ 이중루프(전압 PI + 전류 PI)를 컨버터마다 하나씩 두어 PI 적분기가 총 4개다.

> [!warning] 제어 구조 가정에 종속
> 위 목록은 **ESS 컨버터가 `v_dc`를 제어하고 PV 부스트는 MPPT만 담당**하는 구성을 전제한다.
> 반대 구성이면 `x_vpv`↔`x_vdc`의 역할이 뒤바뀌고 DC 블록 구조도 달라진다. → 미확정 항목 참조

## AC측 14개

| 기호 | 기준 | 근거 |
|---|---|---|
| `delta` | C3 | 전력각. **없으면 동기화 루프가 열린다** |
| `dw` | C3 | 가상 각속도 편차. VSG 관성 방정식의 상태 |
| `Pf` | C2 | 유효전력 LPF. 드룹 입력의 필터링 이력 |
| `Qf` | C2 | 무효전력 LPF |
| `phi_d`, `phi_q` | C2 | 전압 루프 PI 적분기 (dq 각 1개) |
| `gam_d`, `gam_q` | C2 | 전류 루프 PI 적분기 (dq 각 1개) |
| `i_ld`, `i_lq` | C1 | 인버터측 인덕터 전류. **DC→AC 커플링의 수신점** |
| `v_od`, `v_oq` | C1 | 필터 커패시터 전압 |
| `i_od`, `i_oq` | C1 | 계통측 인덕터 전류 |

▸ LCL 필터가 $L_1$–$C$–$L_2$ 구조이므로 dq 축당 3개씩, 총 6개의 회로 상태가 나온다.

> [!danger] δ 포함이 본 모델의 핵심
> GFM 동기화는 $\delta \to P \to \omega \to \delta$ 로 닫히는 루프다. $\delta$가 상태가 아니면 이 루프가 열리고, **약계통에서 가장 먼저 불안정해지는 동기화 모드가 모델에서 사라진다.**
> v0 모델의 최대 결함이 이것이었다. → [[BUG_2026-08-25_sym_구조결함]]

## 제외한 후보와 근거

### SOC (배터리 충전상태)

▸ 시정수가 **시간 단위**. 관심 대역 0.1–100 Hz보다 4~5 자릿수 느리다. (E1)

※ 포함하면 원점 근처에 거의 0인 고유값이 생겨 행렬이 stiff해지고, 수치 조건수가 나빠져 유한차분 검산 정확도가 떨어진다. 소신호 해석 시간 척도에서 SOC는 상수로 봐도 무방하다.

**논문 서술** — SOC 동특성은 대상 대역 대비 준정적이므로 파라미터로 처리했다는 한 문장을 모델링 절에 명시할 것.

### 배터리 단자 전압 `u_bat`

▸ 배터리를 내부저항 포함 정전압원으로 모델링. 단자 전압은 `i_Less`의 대수 함수로 표현되므로 독립 상태가 아니다. (C1 미충족)

※ v0 모델에는 `u_bat`이 상태로 들어가 있었다. 대신 PI 적분기가 3개뿐이어서 전류 루프 하나가 누락된 상태였다.

### PLL 상태

▸ GFM 제어이므로 동기화에 PLL을 쓰지 않는다. 전압 지령의 위상을 스스로 생성하며 그 역할을 `delta`가 담당한다.

※ GFL 모델과의 가장 큰 구조적 차이. 비교 논의에 쓸 수 있다.

### 스위칭 동특성 · PWM 지연

▸ 스위칭 주파수가 관심 대역보다 훨씬 높다. 평균화 모델로 처리. (E1)

※ 다만 178 Hz 부근에 LCL 공진이 있어 대역 여유가 v0 때 가정만큼 크지 않다. CHIL 검증 시 이 근사의 타당성을 실측과 대조할 것.

### MPPT 기준값 `v_pv*`

▸ 상태가 아니라 **입력**. MPPT 알고리즘 자체의 동특성(P&O 갱신 주기 등)은 별도 시간 척도이므로 소신호 모델 밖에 둔다.

## 입력 벡터 $u$

$G$(일사량), $T$(모듈 온도), $P^*$, $Q^*$ 또는 $V^*$, $V_g$, $\omega_g$

▸ **SCR·X/R은 입력이 아니라 파라미터**다. $R_g$, $L_g$를 통해 $A$ 행렬에 들어가며, 동시에 동작점 $x_0$를 이동시킨다. → [[다중동작점_갱신절차]]

## 21 → 22 정정 경위

제안서에는 "21차"로 기재되어 있었으나, 이는 **유도 결과가 아니라 먼저 적어둔 숫자**였다. 물리에서 세면 $8+14=22$가 나온다.

| 선택지 | 내용 | 판정 |
|---|---|---|
| **(a)** 22차로 정정 | 제안서 문구 수정 | ✅ 채택 |
| (b) `Qf` LPF 제거 | Q 순시값을 전압 드룹에 직접 인가 | DSP에 Q 필터가 없을 때만 정당 — 미확인 |
| (c) `v_pv` 준정적화 | DC 7개로 축소 | 부스트 동특성 관찰 목적과 상충 |

※ Phase 2 게이트가 원래 "차수 확정"을 포함하므로 이 시점의 정정은 절차상 문제없다.
※ 심사 대응 — "이렇게 유도됐다"가 "숫자를 맞췄다"보다 안전하다.
