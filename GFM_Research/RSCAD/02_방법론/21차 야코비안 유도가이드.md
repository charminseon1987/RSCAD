# 📐 21차 야코비안 유도 가이드

## 개요

```
비선형 f(x) 21개 방정식
    ↓ 동작점 x₀(SCR_k) 대입
    ↓ SymPy jacobian() 또는 수동 편미분
21×21 야코비안 행렬 A_k
    ↓ linalg.eigvals()
고유값 21개 → 안정도 분석
```

---

## Step 1. 상태변수 정의 (21개)

```
DC측 (8개):
  x1=xPI1, x2=xPI2, x3=xPI3   (PI 적분기)
  x4=upv,  x5=ubat, x6=udc    (전압)  ← x6★
  x7=iLpv, x8=iLbat           (전류)

AC측 (13개):
  x9=Δω                        (VSG 각속도) ★
  x10=Pfilt, x11=Qfilt         (전력 필터)
  x12=φ_vd, x13=φ_vq          (전압루프 PI)
  x14=γ_id, x15=γ_iq          (전류루프 PI)
  x16=iid,  x17=iiq           (인버터 전류)
  x18=uod,  x19=uoq           (커패시터 전압)
  x20=iod,  x21=ioq           (계통 전류)
```

---

## Step 2. 비선형 f(x) 구성

### DC측 (f1~f8)

```python
f1  = iLpv_ref - iLpv              # MPPT PI 오차
f2  = iLbat_ref - iLbat            # ESS PI 오차
f3  = Vdc0 - udc                   # DC버스 PI 오차
f4  = (0.9 - iLpv) / Cpv          # upv
f5  = 0                             # ubat (이상적)
f6  = (iLpv*(1-dpv) - idc_inv) / Cdc  # udc ★
f7  = (upv - (1-dpv)*udc) / Lpv   # iLpv
f8  = (ubat - dbat*udc) / Lbat    # iLbat

# PI 연결 핵심:
# dpv = 0.5 + Ki1*xPI1  ← xPI1이 f6, f7에 연결
```

### AC측 (f9~f21)

```python
f9  = (1 - Pfilt - Dp*Δω) / J    # Δω ★
f10 = wc*(Pmeas - Pfilt)           # Pfilt
# ... (이중루프, LCL, 계통)
```

## Step 3. 핵심 원소 A_k(9,6) 수동 보강

```python
# SymPy로 자동 유도 시 A_k(9,6) = 0
# → 이유: f9는 udc에 직접 의존하지 않음
# → 동작점 선형화에서만 나타남

# 수동 보강 필수:
A_num[8, 5] = idc0 / (J * w0)
# = 0.9/SCR / (J * 2π*60)
```

---

## Step 4. 계통 임피던스 SCR별 갱신

```python
Zg  = 1.0 / SCR
Rg  = Zg / sqrt(1 + XR**2)
Lg  = Rg * XR / w0

# iod, ioq 행 (인덱스 19, 20) 갱신
A[19, 17] =  1/Lg
A[19, 19] = -Rg/Lg
A[19, 20] =  w0
A[20, 18] =  1/Lg
A[20, 19] = -w0
A[20, 20] = -Rg/Lg
```
