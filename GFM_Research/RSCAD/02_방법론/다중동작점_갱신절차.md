# 📐 다중 동작점 갱신 절차

## 한 줄 정의

> SCR_k = {3.0, 2.0, 1.5, 1.0} 각각에 대해 동작점 x₀_k를 계산하고 야코비안 A_k를 갱신하는 절차

---

## 전체 흐름

```
SCR_list = [3.0, 2.0, 1.5, 1.0]
XR_nom   = 1.0  (기준 X/R — 야코비안 갱신은 sweep2d에서)

for k = 1 → 4:
    ① 계통 임피던스 계산 (SCR_k, XR)
    ② PCC 전압 갱신 (Thevenin 1차)
    ③ PV 동작점 갱신 (MPPT)
    ④ DC 버스 전류 계산 (idc0_k) ← DC-AC 커플링 핵심
    ⑤ 동작점 벡터 x₀_k 구성 (21개)
    ⑥ 선형화 유효성 검증 (Δu_pv < 5%)
    ⑦ 야코비안 A_k 계산 및 저장
```

---

## 단계별 상세

### ① 계통 임피던스

```python
Zg_k = Vn**2 / (SCR_k * Prated)
Rg_k = Zg_k / np.sqrt(1 + XR**2)
Xg_k = Rg_k * XR
Lg_k = Xg_k / w0
```

### ② PCC 전압 (Thevenin 1차 근사)

```python
# d축 정렬 기준
Vpcc_k = Vn - (Id0 * Rg_k + Iq0 * Xg_k)
```

> ⚠️ 주의: `Vpcc = Vn - I*Zg*0.5` 형태는 오류  
> ▸ 올바른 식: `Vpcc = Vn - Id*Rg - Iq*Xg`

### ③ PV 동작점 (MPPT)

```python
# 간략화 (Phase 2)
Vpv0_k = 0.8 * Vn   # pu 기준
Ipv0_k = 0.9 / Vpv0_k

# 정밀화 (Phase 3 예정)
# [Vpv0_k, Ipv0_k] = calc_mppt(Vpcc_k, G_nom, T_nom)
# → Villalva(2009) P-V 곡선 기반
```

### ④ DC 버스 전류 ← 핵심

```python
Ppv_k  = Vpv0_k * Ipv0_k
idc0_k = Ppv_k / Vdc0   # = 0.9 / SCR_k (pu 기준)

# → A_k(9,6) = idc0_k / (J * w0)
```

### ⑤ 동작점 벡터 (21개)

```python
x0_k = np.array([
    0, 0, 0,              # xPI1,2,3 = 0
    Vpv0_k, 0.9, 1.0,    # upv, ubat, udc
    0.9, 0.1,             # iLpv, iLbat
    0,                    # Δω = 0
    1.0, 0,               # Pfilt=Pref, Qfilt=0
    0, 0, 0, 0,           # φ_vd,vq, γ_id,iq = 0
    Id0, Iq0,             # iid, iiq
    Vpcc_k, 0,            # uod, uoq
    Id0, Iq0,             # iod, ioq
])
```

### ⑥ 선형화 유효성 검증

```python
du_pv = abs(Vpv0_k - Vpv0_nom) / Vpv0_nom * 100
if du_pv > 5.0:
    print(f"SCR={SCR_k}: Δu_pv={du_pv:.1f}% > 5% → PSCAD 교차검증 필요")
```

|SCR|Δu_pv|유효성|
|---|---|---|
|3.0|0.0%|✅|
|2.0|8.3%|❌|
|1.5|12.5%|❌|
|1.0|16.6%|❌|

### ⑦ 야코비안 저장

```python
A_k, idc0 = build_jacobian_21(SCR_k, XR_nom)
np.save(out_dir / f'A_num_SCR{SCR_k}.npy', A_k)
```
