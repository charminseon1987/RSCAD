# Claude Code 첫 프롬프트 (그대로 복사해서 붙여넣기)

이 저장소는 lab-scholar 프로젝트야. 아래 순서로 진행해줘.

1. `CLAUDE.md`, `docs/SPEC.md`를 읽고, `docs/design/scholar-prototype.html`과 `reference/` 폴더의 파이썬 파일 두 개도 훑어봐.
2. 이해한 내용을 5줄 이내로 요약해줘 (무엇을 만드는지, Claude Code와 웹앱의 역할 분담, 단계 순서).
3. **Stage 0만** 계획을 세워서 보여줘: 만들 파일 목록, 각 파일의 역할, 검증 방법.
4. 내가 승인하면 Stage 0을 구현하고, 완료 기준을 직접 실행해서 결과를 보여줘.
5. Stage 0이 끝나면 멈추고 `docs/CHANGELOG.md`를 작성한 뒤 다음 Stage 진행 여부를 물어봐.

SPEC과 다르게 해야 할 이유가 있으면 구현 전에 먼저 말해줘.
